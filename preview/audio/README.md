# Music

Put your song here, e.g. `our-song.mp3`, then set its name in
`src/config/birthday.ts` → `music.src` (default: `audio/our-song.mp3`).

- The music never autoplays: she turns it on with the "Turn on music ♫" button.
- If the file is missing, the button only controls the soft sound effects.
- Keep it reasonably small (a 128–192 kbps mp3 is plenty).
